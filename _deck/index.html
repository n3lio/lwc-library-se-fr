Component Library

A reusable Lightning Web Components kit shared across the SE France team to speed up Salesforce demos.
Internal asset · SE FR · 2026
01 · 47
Speaker: internal SE-to-SE asset, demo accelerator.

Why this library

Three reasons to reach for it before building from scratch.

Lightning is still where most demos happen

Headless 360 is the future direction, but our customers run on Lightning today — most demos still happen on Account, Contact, Case & Opportunity record pages.

This kit makes those Lightning demos look great without rebuilding common components every time.

Polish you don't have to (re)build

Each component is already designed, themed, bilingual and configurable.

You drop the zip, tune App Builder properties, demo. No CSS to write, no Apex to bend, no boilerplate to copy from previous demos.

One catalog, every SE

Components share the same SLDS theme, the same conventions, the same defaults.

Drops cleanly into any SE demo org (SDO, IDO, custom scratch) without new custom fields — schema-safe by design.

Design principles applied to every component

Visual consistency. Configurable behavior. Zero friction.

Look & feel

  • Homogeneous SLDS theme across the catalog
  • Same border-radius, spacing and typography rhythm
  • Lightning theme accent auto-applied (works on Spring/Summer/Winter themes)
  • French defaults out of the box (configurable to EN)

Behavior

  • Demo-ready, no setup needed
  • Configurable in App Builder (no code change)
  • Bilingual EN / FR built-in
  • Industry-agnostic defaults
  • Schema-safe — works on any demo org without new custom fields
  • Plays nicely with standard Lightning page layouts

Need Components What to do
